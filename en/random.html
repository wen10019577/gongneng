Random integers: draw with or without repetition

Draw up to 100 numbers from an integer range that includes both endpoints, and choose whether duplicates may appear within a single draw.

Updated and rules checked: 2026-09-16 · Calculation notes

Enter the inputs

Check with an example

From the range 1 to 3, drawing 3 numbers without repetition always produces 1, 2, 3, but in no fixed order. Asking for 4 without repetition will warn that the count exceeds the range.

The difference between allowing and disallowing duplicates

Allowing duplicates is like putting each drawn slip back after drawing it; the same number can appear several times. No duplicates is like drawing without putting the slips back. The range includes both endpoints, so 1 to 10 contains 10 possible integers, not 9.

Where the randomness comes from

The tool uses the random number interface provided by the browser, and when mapping values onto the range it discards the part that would cause remainder bias. The no-duplicates mode draws from the remaining positions, so it does not retry endlessly after hitting numbers that were already drawn. Results are generated locally and are not synced to anyone else's device.

Uses and limits

Suitable for classroom exercises, test data and everyday random choices. It does not provide the verifiable process, identity checks or audit records required for a public prize draw, and numbers from a short range must not be used as secure passwords. Each click generates a new set, so save any results you need yourself.
