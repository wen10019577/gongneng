Input rules

Binary accepts only 0 and 1; octal accepts 0 to 7; hexadecimal accepts 0 to 9 and A to F, case-insensitively. A minus sign may be placed at the front. Decimals, commas, internal spaces and 0x prefixes are not accepted. Maximum 256 characters.

Why not convert through an ordinary number first

Ordinary JavaScript numbers cannot represent every very large integer exactly. This tool accumulates a big integer digit by digit, so the decimal 9007199254740993 is not changed into a neighboring number. Invalid characters produce a direct error instead of a result that looks normal but has been truncated.

A negative number here is not two's complement

Enter −10 and the binary result is −1010, expressing the mathematical value negative ten. Two's complement in computing first requires a fixed bit width such as 8 or 16 bits; this tool has no such width convention, so it does not offer two's-complement, floating-point encoding or byte-order conversion.
