Date countdown: how long to go, or how long ago?

Pick a reference date and a target date. The tool distinguishes a future countdown from a past anniversary date, and never approximates a month as a fixed number of days.

Check with an example

With September 16, 2026 as the reference, September 20 is still 4 days away; change the target to September 10 and it was 6 days ago.

Planning with it

When preparing a trip or an event, set the target to the departure day and the reference to today. The result is the remaining date interval; if you need to plan out daily tasks, use the date difference tool to decide whether the departure day itself counts. This tool does not set reminders for you, and it sends no background notifications.

Why the reference date can be changed

A fixed reference date makes plans easy to review afterwards, and lets others reproduce the same result. When the page first opens, it uses your device's local date as the reference; after midnight you need to refresh or adjust it manually. It is not a live, second-by-second countdown.

Not converted directly into "months"

February and March have different numbers of days, so dividing the days by 30 would be misleading. Only calendar days are shown here. A target in the past is described as "days ago", and a target on the reference date itself is shown as "today" — the direction is never hidden inside an absolute value.
